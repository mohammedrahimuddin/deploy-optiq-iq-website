# Premium React Software Company Website

React + Vite multi-page website starter. White-first premium design, responsive layouts for desktop/tablet/mobile, service and solution content, searchable/filterable technology catalogue, methodologies, outsourcing, about, and contact page.

## Run
1. Install Node.js LTS.
2. Extract ZIP and open folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the localhost URL printed in terminal.

## Hostinger
Run `npm run build`, then upload the contents of `dist/` to `public_html`. Upload the included `.htaccess` file too for SPA route fallback.

## Before publishing
Replace temporary company name/logo and `hello@example.com`. Contact form is currently demo-only; connect a real backend/email/CRM service. Verify technology expertise and add real contact details, privacy policy, and approved company material.
